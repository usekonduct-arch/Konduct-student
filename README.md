# Konduct for students

The rider app: students fund a wallet and pay campus shuttle and bike fares by scanning the code on the vehicle. Pilot campus: UNIOSUN.

| | |
| --- | --- |
| App id | `com.konduct.rider` |
| Firebase | project `konduct-10ffb`, app `1:1046053007846:android:11cc874f67b1250807a627` |
| Backend | [Konduct-backend](https://github.com/usekonduct-arch/Konduct-backend) (Cloud Functions, region europe-west1) |
| Sister app | [Konduct Driver](https://github.com/usekonduct-arch/Konduct-Driver) |

```
flutter pub get
flutter run
flutter test
```

On the team PC, use the real SDK at `C:\flutter\src\flutter\bin\flutter.bat` (the `flutter` on PATH is an empty stub).

## Demo mode

`flutter run --dart-define=KONDUCT_DEMO=true` runs without Firebase on `DemoAuthRepository`:
any email signs up (`taken@konduct.app` plays an email already in use). Student ID `DUP123` plays an ID that is already registered.

## Sign-in flow

Welcome → email and password (create account or sign in; email isn't verified yet) → name and student ID (one account per student ID per campus) → transaction PIN → ready.

The screen is chosen from the Firebase ID token's custom claims (`role`, `pin`, `status`, `name`),
which only the backend can set, so a relaunch needs no network call.

## Layout

- `lib/app/`: `AppInfo` (name, role, palette) and `AppConfig` (backend region, campus), bootstrap
- `lib/auth/`: repository interface, Firebase and demo implementations, controller, gate, screens
- `lib/ui/kit.dart`: Pressable, KButton, Keypad, Shake, CodeSlots, PinDots, KMark
- `lib/ui/scene/`: the korope bus, students and campus, ported from the landing page's SVG art
- `lib/theme/tokens.dart`: palette and type, shared look with the landing page and the driver app
- `lib/firebase/options.dart`: generated by FlutterFire

The design system (theme, kit, scenes) is a copy of the driver app's. Keep visual changes in
step by hand, or move it into a shared package once there is a repo for one.

## Re-generating the Firebase config

```
flutterfire configure --project=konduct-10ffb --platforms=android --android-package-name=com.konduct.rider --out=lib/firebase/options.dart --android-out=android/app/google-services.json --yes
```
